# LivelyCura HRM follow-ups: explain the issue, give the options, then the recommendation

- Date: 2026-11-25
- Author: the user (product owner), during the LivelyCura HRM follow-ups work in a Claude Code session
- Recorded from: the user's own message (quoted verbatim), relayed by the session agent

## Context

The session presented the next HRM follow-up item with only a single recommendation. The user pointed back to how an earlier session had presented items. That earlier shape, for each item:

1. The issue explained: how it works today, in plain words, with an example person.
2. The options (suggestions), numbered, each saying what it covers or leaves out, including options that won't work and why.
3. "My recommendation": the pick and the reasons for it.

After the session re-presented the item in this shape, the user picked "Option 1" right away.

## The user's words (verbatim)

- "on the other context, you explain the issue and suggestions plus your recomendation"

## Rule

1. Present each item as: the issue (how it works today, plain words, an example person), then numbered options with what each covers or leaves out (including options that won't work, and why), then "My recommendation" with the pick and the reasons.
2. A single recommendation on its own, without the issue and the options, is not enough for the owner to decide.
