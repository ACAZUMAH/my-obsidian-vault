# LivelyCura Admin Notification Inbox And Courier Configuration Correction

Date: 2026-09-26
Source: Direct user correction during LivelyCura Admin Portal implementation

## Correction

The Admin notification feature belongs behind a notification icon button in the main header. Activating the icon opens the administrator's notification inbox.

Courier notification configuration remains in the Courier area at its established configuration location. It is a Courier settings surface for rider delivery notification behavior and must not be removed merely because the notification inbox belongs in the header.

## Durable Distinction

- Header notification icon: personal operational notification inbox for the signed-in administrator.
- Courier Configuration: platform Courier settings, including rider delivery notification controls.
- These surfaces serve different jobs and must not be combined or substituted for one another.

This correction supersedes the earlier inference that the user's rejection of an Admin notification implementation meant removing Courier notification configuration entirely.
