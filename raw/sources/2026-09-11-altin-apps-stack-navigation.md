## Scope and implementation interpretation

Apps remains the center bottom-bar action and opens a root-stack directory with a header Back button. Home, Search, Notifications, and More remain the actual tabs; the selected tab remains underneath Apps. This replaces the earlier five-route tab contract while retaining five visible bottom-bar controls.

The user also requests another Order and Tip detail refinement. Existing shared-composition, feature ownership, React.FC, Conditional, skeleton, intervening-edit preservation, and production read-only constraints continue to apply. No new visual design has been accepted by the user in this instruction.
