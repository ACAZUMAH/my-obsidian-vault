## Rules

1. Report and decide only the current feature's items.
2. A finished feature stays closed. Don't reopen it with new findings, even when the current feature's change caused them.
3. Items for a later feature are parked silently and raised only when that feature is reached; parked items are not listed to the user.
4. Don't call a message vague, or flag it for rewording, when it already tells the user what happened.
