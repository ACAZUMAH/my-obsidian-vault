## Core Claims

- Conversation-based project harvesting requires direct evidence from a relevant Hermes conversation.
- Filesystem and Git-root discovery are not substitutes for conversation evidence and cannot independently justify a project page or durable claim.
- Repository inspection is verification evidence only after a relevant conversation has established the project and claim scope.
- Magical Goodall, mywork Git History Generator, Playground, and Portfolio Mock-up Prototype were unsupported repository-derived pages and must be deleted.
- The canonical user-confirmed name is Let's Ride Backend, not Cando Backend.
