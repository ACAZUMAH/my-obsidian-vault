## Core Claims

- Create a new LivelyCura project for a food brand named Pice.
- Pice is a mobile food-ordering brand in the same product category as CheckCity.
- CheckCity is a functional reference, not the Pice brand identity; Pice must remain a distinct brand.
- Apply the established Obsidian-backed new-project bootstrap workflow rather than creating placeholder files.
