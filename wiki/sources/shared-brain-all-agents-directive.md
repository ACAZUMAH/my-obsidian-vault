## Core Claims

- Every Hermes profile and Codex should use one consistent Obsidian second brain.
- The user will run these agents simultaneously, so long-form knowledge must not diverge by profile or tool.
- Communication should remain concise and sophisticated while explaining relationships and rationale so the user can learn the system.

## Useful Details

- Per-agent startup context should remain compact and point to the canonical vault.
- Role-specific profile memory can coexist with the shared vault, but duplicated shared knowledge should be promoted into Obsidian.
- Repository `AGENTS.md` files remain project-specific layers over global shared-brain guidance.
