# Obsidian

## Summary

Obsidian is the intended human-facing interface for this LLM Wiki. The agent edits markdown files; the user browses, reviews, links, searches, and visualizes the wiki in Obsidian.

## Known Facts

- Obsidian can display the wiki as a local markdown vault.
- Graph view helps reveal hubs, isolated pages, and the shape of the knowledge base.
- Obsidian Web Clipper can convert web articles into markdown raw sources.
- Obsidian can download linked attachments locally, which helps preserve images and other assets.
- Plugins such as Marp and Dataview can extend the wiki with presentations and metadata-driven views.
- The active vault path is `/Users/acazumah/Documents/Work Space`.
- Every Hermes profile and Codex resolves or references this vault as the canonical long-form second brain.
